ℹ️ Informations importantes

Cette trousse pédagogique utilise Claude (Anthropic) pour vous fournir des recommandations pédagogiques intelligentes.

Vos questions seront transmises aux serveurs d'Anthropic (États-Unis) de manière chiffrée (HTTPS) via un serveur intermédiaire sécurisé (Netlify).

✅ Sécurité et suppression des données

Données supprimées automatiquement : Vos données sont supprimées immédiatement après chaque utilisation du chatbot. Aucune donnée n'est conservée sur nos serveurs Netlify.

Communication chiffrée : Toutes les communications sont protégées par chiffrement HTTPS.

Aucune donnée personnelle requise : Vous pouvez utiliser cette trousse de façon entièrement anonyme. Ne partagez pas d'informations sensibles.

📋 Vos droits selon la Loi 25 (Québec)

  • Droit d'accès : Vous pouvez demander à voir vos données
  • Droit de rectification : Vous pouvez corriger vos données
  • Droit à l'oubli : Vous pouvez supprimer vos données locales via le bouton « Effacer toutes mes données »
  • Droit de connaître les transferts : Vos données sont traitées par Anthropic (États-Unis) conformément à sa politique de confidentialité
